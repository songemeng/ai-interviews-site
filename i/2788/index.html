Anthropic 的 Cat Wu 表示，未来，AI 将在你意识到自己的需求之前便预判到它们

Lucas Ropek 太平洋夏令时间 2026年5月13日 12:28

当整个科技行业都聚焦于 AI model 之际，Anthropic 正经历着非同凡响的一年。

该公司有望很快超越其主要竞争对手，因为它正寻求在一轮融资中筹集数百亿美元，估值将达到约 9500 亿美元（OpenAI 在 3 月的融资中估值为 8540 亿美元），而且企业客户越来越倾向于选择 Claude 而非 ChatGPT。最近一份报告显示，Anthropic 最近在企业客户中超越了 OpenAI，自 2025 年 5 月以来市场份额翻了四倍。

Anthropic 负责 Claude Code 与 Cowork 的产品负责人 Cat Wu 是这一成功的关键人物。自 2024 年 8 月加入公司以来，Wu 协助 Claude 度过了关键阶段，将其从一个纯信息型聊天机器人升级为编码工具，乃至更多领域。Wu 负责监督新功能的开发，她经常与 Boris Cherny 搭档，后者是 Anthropic 技术团队的核心成员，也是 Claude Code 的创建者，两人因此被形容为 Anthropic 的“Batman and Robin”。

Wu 在上周于旧金山举办的第二届年度 Code with Claude 大会上与我进行了对谈，讨论了她对产品战略的思考，以及她希望未来使用 Claude 的体验将如何演变。

本访谈经过编辑，以求简洁与清晰。

当你审视产品战略时，其中有多少是针对同行或竞争对手的被动反应？你会考虑这一点吗？

我们设计的核心目标是保持在指数级增长的轨道上，因此我认为，在整个团队中，我们向每个人灌输的理念是 AI 会持续变好。对我们来说，只需坚守这一前沿即可。我们不会考虑竞争对手。我觉得如果你总想着竞争对手，你就会永远比自己的最快执行速度慢两周，甚至一个月。所以这通常不是保持领先的最好方式。

Anthropic 去年至少发布了六个模型，今年已经发布了几乎同样多的数量。你预计这种开发速度会持续下去吗？

我们希望它能继续下去（笑）。我认为模型仍在以非常稳定的速度改进，因此我们应该能够继续与我们的用户分享这些进展。我认为部署方式可能会有所不同——就像我们对 Glasswing 的处理方式一样，但尽可能我们希望这种智能惠及更多人，而且必须以非常安全的方式来处理，这就是为什么我们以[我们所采取的方式]处理了 Glasswing。

[Glasswing 是 Anthropic 于 4 月发起的一项倡议，邀请了一小批合作伙伴组织——包括 Amazon、Apple、CrowdStrike 和 Microsoft 等公司——来访问其新的网络安全模型 Mythos。与 Anthropic 许多其他 AI 模型不同，Mythos 不会进行公开发布。该公司声称，他们担心这个旨在扫描代码库以发现软件漏洞的模型过于强大，可能被不良行为者武器化。]

你在之前的采访中说过，工作的未来基本上是员工管理成群的 agent。但这似乎最终可能导致一种局面：agent 比人类更擅长这份工作，或者对工作了解得比人类更深。

我认为如果你自己不会做这项工作，管理 agent 就会极其困难。管理者仍然需要是他们所在领域的专家。这是很多人必须学习的一套新技能，但管理 agent 其实与管理人非常相似，因为你必须理解，比如，agent 为什么会犯这个错误？它是否误解了我的指令？我的请求是否描述得不够具体？你必须具备调试它的能力。

不过，长期目标看起来确实是缩减团队规模。因为如果有 agent 在做一份工作，那你就不需要实习生了，对吧？

理想情况下，我认为思路是让每个人都能完成更多工作。我觉得，对每个人的工作来说，总有一部分是非常枯燥乏味的。对我来说，就是回复邮件。我认为每个人生活中都有这样一部分……所以我希望它 [AI agent] 能真正承担这些，然后每个人就都会有很多很酷的东西想要在[业余时间]去搭建。

在接下来的六个月里，你们最期待的是什么？

我认为下一个大趋势是主动性。去年我们还处于同步开发的世界。现在，人们正在转向常规流程，比如将客户支持工单的回复自动化。而我认为下一步是，Claude 了解你从事的工作，然后直接为你搭建好一部分自动化流程。
